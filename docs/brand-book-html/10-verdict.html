Verdict design

The single highest-stakes surface in the entire product. Every other screen sets it up.

The three states

COMPATIBLE
No declared allergens on your profile.
Cleared against your profile.
UNCERTAIN
Your call.
May contain tree nuts.
AVOID
Skip this.
Contains peanut.

The layout (locked)

Single layout for all three kinds. Only headline word, accent color, and mascot mood change. Users learn one screen.

Tone pill anatomy

Background: accent color at 10% opacity (rgba ending in 1A)
Border: accent color at 25% opacity (rgba ending in 40)
Dot: 6px circle in accent color
Label: all-caps, xs, weight 700, +1.2 letter-spacing, in accent color
Padding: 8 horizontal, 4 vertical

Why NOT a status-color flood

Yuka floods red/yellow/green across the entire screen. It works for them, but:

  1. It feels alarming. BUD's brand is calm.
  2. It's the number-one visual feature an AI-slop generator would produce.
  3. It looks the same as MyFitnessPal, FoodieScore, every other 2020s health app.
  4. It violates our 85% neutral color discipline.

BUD's restrained card pattern is harder, more designed, and more trustworthy. Wealthsimple's "your portfolio is down" screen doesn't turn red. It shows a small red number. We do the same.

Motion choreography

ElementAnimationTiming
MascotFadeIn 280mst = 0
Header block (pill + headline + reason)FadeInUp 320mst = 80ms
Detail cardSlideInDown 300mst = 160ms
CTAmounts with parentt = 0

Creates a cascade: mascot appears, headline rises, card drops in. Reads as composed, not jumpy. Same pattern Phantom Wallet uses for swap confirmations.

Copy patterns

Reasons should be specific and short. The user has 2 seconds to read this on the way out of the grocery aisle.

VerdictPatternExample
compatible"Cleared against your profile.""Cleared against your profile." / "Nothing flagged."
avoid"Contains X.""Contains peanut." / "Contains milk, soy."
caution"May contain X.""May contain tree nuts."
unknownHonest about why"I couldn't read the label clearly. Try a different angle?"
Never add filler. Not "Unfortunately, this contains peanut." Not "Looks like this might be okay." Cut the qualifier.
