Chapter 08

Motion and interaction

Subtle and slow. Default ease over 300ms. No bouncy springs. No confetti.

Motion principles

Subtle and slow. Default ease: cubic-bezier(0.4, 0, 0.2, 1) over 300ms.
Floating animation for hero elements: vertical translate -12px over 4s, ease-in-out, infinite. Restrained.
Pulse glow for primary CTAs only, never on secondary or tertiary. Sage glow, never green-neon.
Fade-in-up on scroll for sections, stagger 0.1-0.5s between elements.
No bouncy spring physics. No confetti. No micro-interactions that beg for attention.

Easing

  • Standard: cubic-bezier(0.4, 0, 0.2, 1)
  • Ambient loops (mascot bob): Easing.inOut(Easing.quad)
  • Entries: Easing.out(Easing.cubic)
  • Banned: Easing.linear, Easing.bounce

Skeleton loaders

Match the final layout shape. Shimmer left-to-right at 1.2s cycle. Never ActivityIndicator spinners in shipped UI.

Reduced motion

iOS + Android "Reduce Motion" system setting respected via useReducedMotion() from Reanimated:

  • Spring transitions degrade to instant
  • Fades shorten from 280ms to 120ms
  • Bob animation pauses
  • Confetti suppressed
