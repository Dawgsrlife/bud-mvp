Typography

Four-font editorial system. Sora for structure. Fraunces Italic for emotional accents. Inter for body. IBM Plex Mono for data. Discipline beats variety.

The four families

RoleFamilyWeightUsed for
Wordmark + displaySora600"bud" wordmark, hero headlines, screen titles, CTA buttons
Emotional accentFraunces Italic400-500Tagline, pull quotes, hand-on-shoulder moments
BodyInter400-500-700Body copy, subheads, helper text, ingredient lists

No fifth family. No Roboto. No Helvetica. No system-ui fallback in production. The four families above are the canon.

Pairing rules

  1. Sora carries structure. Wordmark, hero headlines, screen titles, CTAs. Sora is the load-bearing family.
  2. Fraunces Italic is rationed. Once per surface. Once per email. Never twice in the same paragraph.
  3. Inter handles everything else. 80% of the words on any screen are Inter.
  4. Plex Mono only on labels, data, code, and URLs. Never body. Never long copy.
  5. No mixing within a single line. A line is one family. Cross-family pairing happens vertically, between lines.

Retired rules (v4 → v7)

v4 rulev7 statusWhy
"Italic prohibited"RetiredFraunces Italic is a locked role. Italic is canon, not banned.
"No serif + sans mixing"RetiredFraunces Italic + Sora + Inter is the editorial system. Mixing is the whole point.
"Inter only"RetiredFour families are canon. Inter is one of four, not the only one.

Still banned

  • Underline (except explicit links)
  • Font sizes between scale steps
  • Inter weights 300, 600, 900
  • All-caps body text. All-caps is for Plex Mono labels only.
  • Letter-spacing on body Inter (zero, always)
  • Drop shadows on text
  • Mixing Plex Mono into body Inter copy
  • Fraunces Italic used twice in the same paragraph
