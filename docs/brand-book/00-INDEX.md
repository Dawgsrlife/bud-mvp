# BUD Brand Book

The single source of truth for what BUD looks like, sounds like, and feels like. Modeled on the structure used by Pentagram client brand books, Stripe Press, and Linear's internal design system.

**Version:** v4 (iteration over older single-doc drafts in `../design/brand-book-v1..v3.md`)
**Last updated:** 2026-05-15
**Owner:** Alex Meng (founder), iterated with Kasumi-chan as design partner.

---

## How to use this brand book

This is a **living document set.** Each chapter is its own file. The INDEX (this page) is the table of contents.

Read top to bottom on first pass. Reference specific chapters when working on specific surfaces (designing a screen, writing copy, building a marketing asset).

When you change something, update the chapter's `Last touched` line + leave an entry in the chapter's `Iteration log` section.

## What's locked vs in-flight

| Locked | In-flight |
|---|---|
| Typography (Inter, 6-step scale, 3 weights) | Brand color (4 ladder variants under live test) |
| Motion principles (spring physics, no linear easing) | Logo wordmark (current is text-only, no real lockup yet) |
| Voice ladder + ban-list | Mascot face evolution (eyes-only v0, may add mouth v1) |
| Mascot mood map (idle/happy/thinking/warning) | App icon direction |
| Verdict screen pattern (restrained card, not status flood) | Photography style |
| No em-dashes, no stock photos, no Material defaults | Social templates |

## Working principles for everyone who touches the brand

1. **Quietly confident, hand-on-shoulder warm.** Never shouty. Never anxious.
2. **Specific over generic.** "Contains peanut" beats "may contain allergens." Verdict language is concrete.
3. **Generous with the user, ruthless with itself.** Free safety. Premium only when premium earns it.
4. **Tactile precision.** Every interaction has weight. Springs settle. Buttons respond. Numbers roll.
5. **Restraint is the brand.** When in doubt, less.
